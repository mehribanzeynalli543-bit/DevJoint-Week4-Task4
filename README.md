# Dev Joint - Week 4 Task 4: Form Validation

Bu tapşırıqda `React Hook Form` kitabxanası vasitəsilə qeydiyyat formunun validasiyası və idarə olunması həyata keçirilib.

## Xüsusiyyətlər
- **React Hook Form:** Performanslı və asan idarə olunan form state idarəetməsi.
- **Validasiya qaydaları:**
  - **Ad:** Minimum 3 simvol tələbi.
  - **E-poçt:** Düzgün email formatı yoxlaması (Regex vasitəsilə).
  - **Şifrə:** Minimum 6 simvol tələbi.
- **Asinxron göndərilmə:** Göndərilmə zamanı (`isSubmitting`) düymənin deaktiv olunması və saxta gözləmə simulyasiyası.
- **UI/UX:** Tailwind CSS ilə səliqəli və müasir mərkəzləşdirilmiş dizayn.
